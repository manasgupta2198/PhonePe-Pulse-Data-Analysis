# 📱 PhonePe Pulse Data Analysis

Python-based exploratory data analysis of the **PhonePe Pulse** dataset, focused on digital-payment adoption, transaction trends, user growth, device usage, and state/district-level patterns across India.

## 🎯 Project Objective

The goal is to transform raw PhonePe Pulse data into clear analytical insights around:

- Digital-payment activity over time
- State and district adoption patterns
- Registered users and transaction behaviour
- Device-brand usage
- Demographic and population indicators

## 🛠️ Tools & Technologies

- **Python**
- **Pandas** — data manipulation and analysis
- **NumPy** — numerical operations
- **Matplotlib** — data visualization
- **Jupyter Notebook / Google Colab** — analysis environment
- **Excel** — source dataset

## 🔎 Analysis Areas

### Transaction Analysis
- Transaction trends across time
- State-wise transaction activity
- Transaction-type analysis
- Geographic comparison of digital-payment activity

### User Analysis
- Registered-user trends
- State-wise user distribution
- User-to-population analysis
- District-level user patterns

### Device Analysis
- Device-brand usage
- User distribution by device brand
- Regional device-adoption patterns

### Demographic & Geographic Analysis
- District-level demographics
- Population-related indicators
- Population-density and adoption patterns
- State and district visual comparisons

## 📊 Key Analytical Questions

1. How has PhonePe transaction activity changed over time?
2. Which states contribute the most to transaction activity and registered users?
3. Which districts show strong or weak digital-payment adoption?
4. Which device brands are most commonly used by PhonePe users?
5. How does user adoption compare with population indicators?
6. What geographic patterns can be observed in digital-payment usage?

## 💡 Business Value

The analysis helps identify regions with strong digital-payment adoption, understand user and device patterns, and highlight areas with potential for further digital-payment growth.

## ▶️ How to Run

1. Download or clone this repository.
2. Open `phonepay_pulse_data_analysis.ipynb` in Jupyter Notebook, JupyterLab, or Google Colab.
3. Keep the Excel dataset available in the working directory expected by the notebook.
4. Run the notebook from top to bottom.
5. Review the generated tables, charts, and analytical observations.
