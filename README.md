# 📱 PhonePe Digital Payments Case Study

Python-based exploratory data analysis of the **PhonePe Pulse** dataset, covering transaction trends, transaction types, device usage, registered users, district demographics, data quality, and advanced analysis across India.

## 🎯 Project Objective
Analyze PhonePe Pulse data to understand digital-payment adoption, transaction behavior, device usage, geographic patterns, and population-related trends.

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook / Google Colab
- Excel

## 📊 Case Study Coverage
The notebook follows the complete case-study workflow:

- Data loading and understanding across five datasets
- Row sampling, descriptive statistics, data types, and missing-value analysis
- State- and district-level transaction analysis
- Top and bottom state analysis
- Transaction-type analysis by state and quarter
- Device-brand and registered-user analysis
- District population analysis
- Average Transaction Value (ATV) analysis
- App-opens trend analysis
- District-code mapping and CSV output
- State vs district data-quality reconciliation
- User-to-population ratio
- Population density vs transaction-volume correlation
- Average transaction amount per user
- Device-brand usage ratio
- State-level and transaction-type visualizations
- Business insights and recommendations
