# PhonePe Pulse Data Analysis

## Project Overview
This project analyzes the PhonePe Pulse dataset using Python and Pandas to identify transaction trends, user behavior, device usage, and demographic insights.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Dataset
- State Transactions & Users
- State Transaction Split
- State Device Data
- District Transactions & Users
- District Demographics

## Key Insights
- Transaction trends over time
- User to population ratio
- Device brand usage analysis
- Population density correlation
- State-wise visualizations
